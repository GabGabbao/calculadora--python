# 🧮 Calculadora em Python

Projeto de uma calculadora com interface gráfica feita em Python usando Tkinter.

## Funcionalidades

* Operações básicas (+, -, *, /)
* Interface gráfica (GUI)
* Histórico de cálculos
* Bloqueio de letras no teclado
* Executável (.exe)

## Como executar

### Rodar com Python:

```bash
py calculadora.py
```

### Rodar como .exe:

Abra o arquivo na pasta `dist`

## Ferramentas usadas

* Python
* Tkinter
* PyInstaller
